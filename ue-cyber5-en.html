SAE5.Cyber.03_FA – Advanced Security and Supervision of an IS

Objectives

  • Master professional perimeter security solutions
  • Understand enterprise secure network architectures
  • Obtain a recognized cybersecurity certification

Description

Training and certification on Stormshield Network Security (SNS) firewalls, a leading solution in France for protecting enterprise network infrastructures.

Training Content

  • 🔒 SNS firewall administration: configuration, security policies, NAT
  • 🌐 Advanced filtering: filtering rules, application control, IPS/IDS
  • 🔐 VPN: site-to-site and secure remote access
  • 📊 Monitoring and logs: supervision, security event analysis
  • 🛡️ Advanced protection: intrusion detection, anti-malware protection

Certification Obtained

Stormshield Network Security Administrator (SNSA)

This certification validates the ability to deploy, configure, and administer Stormshield solutions in a professional environment.

Skills Acquired

  • Enterprise firewall deployment and configuration
  • Network security policy implementation
  • IPsec and SSL VPN configuration
  • Security incident analysis and response
  • Network security supervision and monitoring
