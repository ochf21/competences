UE3.Cyber.4 – Secure an Information System

This module trained us to detect, analyze, and remediate vulnerabilities: creating intrusion scenarios, applying countermeasures, and writing audit reports; all based on core components CE4.01 to CE4.05.

SAE3.Cyber.04 – Discover Pentesting

Objectives

  • Understand the process of intrusion auditing: reconnaissance, exploitation, post-exploitation.
  • Get familiar with core tools (nmap, hydra, gobuster, Burp Suite, metasploit).

Activities

During the SAE, we completed:

  • 💡 26 Root Me challenges (web, network, crypto) to strengthen our methodology.
  • 🛠️ Guided labs: network scan, HTTP brute-force, XSS & SQL injections.

Result

3rd place on the Root Me Academic ranking: 1,470 pts.

Skills Gained

  • Information gathering and mapping an information system.
  • Exploiting common vulnerabilities (OWASP Top 10).
  • Writing audit reports and recommendations.

SAE4.Cyber.01 – Secure an Information System

Objectives

  • Deploy and secure a complete network infrastructure
  • Set up critical services with high availability
  • Implement a Public Key Infrastructure (PKI)
  • Configure directory and authentication services

Deployed Services

During this project, we deployed the following services:

  • 🌐 Secure DNS (BIND9): configuration of forward and reverse DNS zones
  • 🔐 Complete PKI: creation of root, server, and client certificates
  • 📁 Secure LDAP directory: centralized authentication with LDAPs (TLS)
  • 🔒 OpenVPN: secure remote access with routing and filtering
  • 📂 NFS with PAM authentication: secure file sharing
  • 🌍 High-availability Web server: Apache2/Nginx with load balancing and HTTPS
  • 📧 Secure email system: Postfix (SMTP) + Dovecot (IMAP) with LDAP authentication
  • 🔄 Authenticating Squid proxy

Technical Skills Acquired

  • Network architecture: IP addressing plan, advanced routing, filtering rules
  • Virtualization: creation and management of Debian Linux VMs on VirtualBox
  • Security: implementation of TLS/SSL encryption across all services
  • High availability: configuration of redundant services
  • Analysis: reading and interpreting system logs

Presentation and Evaluation

10-minute technical presentation (5 min + 5 min Q&A) including:

  • Video demonstration of deployed services
  • Detailed network architecture diagrams
  • Justification of technical choices
  • Security risk assessment

Result

Successful deployment of a complete and secure infrastructure, demonstrating mastery of critical network services and security best practices.
